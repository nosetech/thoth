# デザイン指示: ログ閲覧画面（#15）

Claude のチャットで、既存のアーティファクト「thoth — アプリ管理 UI プロトタイプ」（#8）に追記・更新するための指示。デザインの参照方法は `CLAUDE.md` の「画面デザインの実装ルール」を参照。更新後は `CLAUDE.md` のデザイン URL・ファイル一覧も更新する。

```
既存のアーティファクト「thoth — アプリ管理 UI プロトタイプ」の【LOGS 画面】(今は仮画面)を実装してください(他の画面・既存のレイアウト・配色・操作は変えず、LOGS 画面のみ追記)。【前提】backend は各サービスの log_paths(複数可、ローテーション後の世代ファイル含む)を読み、末尾N行・検索・レベル絞り込みを返します。ログは常時追従(tail)でき、ローテーション(日次・世代ファイル)を検知しても追従を続けます。巨大ファイルは末尾の一部だけを読み、全体は読み込みません。【必要な要素】1)対象の選択: アプリ→サービス→ログファイルの順に選ぶ(ログファイルが複数あるサービスはファイル名で切替。モバイルでは1行ずつのセレクト)。2)ログ本文: 等幅フォント、行番号、レベル(ERROR/WARN/INFO/DEBUG)ごとのアイコン+文言+色(色だけに頼らない)、長い行は折り返し切替。3)検索とフィルタ: キーワード検索(一致箇所を強調、一致件数表示)、レベル絞り込み(複数選択)。4)追従(tail)のオン/オフ: オンの間は5秒ごとに新しい行を末尾へ追加して自動で最下部へスクロール。上へスクロールしたら追従を自動で止め「最新へ移動」ボタンを出す。5)ローテーション検知: 追従中にファイルが切り替わったら、本文の上部に「ログがローテーションされました(HH:MM:SS)」の区切り行を入れ、新しいファイルから続ける。世代ファイル(app.log.1 など)も選択肢に表示する。6)大きいファイル: 末尾の一部のみ表示している場合は「末尾 N 行のみ表示(ファイルサイズ 120MB)」の注意バーを出し、「さらに前を読み込む」ボタンで過去へ遡れる。7)状態: 読み込み中、ログパス未設定(「このサービスにはログが設定されていません」)、ファイルなし/読み取り不可、取得エラー(再試行ボタン)、検索結果0件の各状態。8)モバイル(375px)とデスクトップの両方、アクセシビリティ(キーボード操作・focus-visible・ライブリージョンは過剰に読み上げない)を満たす。【出力】既存のモックデータに、deep-tracker / backend の複数世代ログ、巨大ファイル、ログ未設定、ファイルなし、取得エラーの各ケースを足し、表示が実際に切り替わる状態にしてください。
```

## 実装時の注意

- モックのダミーデータ・デモ用スイッチは実装に含めない。データは `GET /api/logs`（対象一覧）と `GET /api/logs/read`（本文）から取得する。
- 見た目は cosmic-ui のコンポーネントに従う（値はデザインから移植しない）。
